# Phi-Family Zone (PhiMorph / PhiSwarm)

Selects the zone for whichever phi-family oscillator is active (the same two menu slots serve both). For PhiMorph, each zone position produces a distinct waveform shape via phi-triangle evaluation; for PhiSwarm, it selects a synchronization regime (slave detune ratios, coupling, temperature — see docs/dev/phi-swarm-sync.md).

Available when oscillator type is any phi-family oscillator.
