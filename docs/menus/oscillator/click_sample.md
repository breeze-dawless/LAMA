# Click sample (Kick synth mode)

In the **Kick** synth mode the noise oscillator can play a sample instead of noise - a click, a transient, a snap or a
layer of a sampled kick - on every note, from the start, at its own speed. Its volume is the **Noise** level, so
everything that's patched or automated on the noise level controls the click too.

- **Select**: opens the file browser (WAV files). Choose a file to load it.
- **Shift + select**: back to plain noise.
- Shortcut: press the noise pad twice.

Any WAV works (8 / 16 / 24 / 32-bit or float, mono or stereo - mixed to mono, any sample rate). The first 1.5 seconds
(at 44.1 kHz) are kept in memory, which is plenty for a click layer; longer files are cut and faded there. The file is
saved with the sound and loaded with it.

Available when the synth mode is Kick.
