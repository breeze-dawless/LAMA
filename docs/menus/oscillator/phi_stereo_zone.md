# Phi Stereo Zone

Zone-style stereo control of the PhiSwarm oscillator. Position within each of the eight zones sets the stereo AMOUNT (every zone starts mono, so the knob's origin is always mono); the zone selects the stereo CHARACTER of the slave separation. Zones: Slim, Near, Open, Tilt, Wide, Sway, Split, Vast.

Available when oscillator type is PhiSwarm.
